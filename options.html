GitHub PR Quick Approve

Approve pull requests, or jump straight to writing a review, with a single keyboard shortcut on any PR tab. Uses your normal GitHub login, no token needed.

1

Keybinding

Click the field and press your desired key combination.

Opens Review changes with the cursor in the comment box, without approving.

The two shortcuts must be different.

2

Approval message

Leave empty for a silent approval, or add a message (e.g. "LGTM!").
