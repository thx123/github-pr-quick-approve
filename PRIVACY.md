# Privacy Policy — GitHub PR Quick Approve

**Last updated:** 2026-03-19

## Data collected

This extension stores the following data locally in your browser (via Chrome's synced storage):

- **GitHub Personal Access Token** — used to authenticate API requests
- **Keyboard shortcut preference** — your configured keybinding
- **Approval message** — your configured review body text

## How data is used

- Your GitHub token is sent **only** to `api.github.com` to submit pull request reviews on your behalf.
- No data is sent to any other server, third party, or analytics service.
- No data is sold, shared, or transferred to third parties.

## Data storage

All data is stored locally in your browser using Chrome's `storage.sync` API. If you are signed into Chrome, this data may sync across your devices via your Google account. You can clear all extension data by resetting to defaults in the extension options or by uninstalling the extension.

## Permissions

- **storage** — required to save your preferences and token
- **host_permissions (api.github.com)** — required to call the GitHub API

For questions or concerns, open an issue at [github.com/be0x74a/github-pr-quick-approve](https://github.com/be0x74a/github-pr-quick-approve/issues).
